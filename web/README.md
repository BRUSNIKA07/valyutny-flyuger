# web

Сайт флюгера: одна страница `index.html` без сборщиков и внешних библиотек. Её отдаёт наш сервер, поэтому отдельно открывать файл не нужно.

## Что на сайте

Тёмный сайт в стиле биржевого терминала, четыре вкладки (`#market`, `#device`, `#analytics`, `#settings`). Сверху бегущая строка с курсами и время во Владивостоке и Москве.

- Рынок: слева список валют, в центре большой график выбранной валюты (периоды 1Н, 2Н, 1М, всё; область, линия или столбцы; перекрестие с ценой и датой при наведении), справа конвертер валют по курсу ЦБ и мини-панель устройства. Ниже таблица «Обзор рынка» с изменением за день, неделю и месяц, минимумом и максимумом и графиком, сортируется по клику на заголовок.
- Устройство: матрицы точками, шкала флюгера, светодиод и пищалка для выбранной валюты, объяснение каждого элемента и таблица по всем валютам.
- Аналитика: курсы по дням за весь период, сравнение всех валют в процентах и статистика периода (лучший и худший день, дни роста и падения).
- Настройки: время показа валюты, порог сильного изменения, какие валюты показывать на устройстве, состояние системы.

Страница подстраивается под телефон и обновляет данные раз в минуту.

## Как открыть

```
cd server
.venv\Scripts\python -m uvicorn app.main:app --reload --host 0.0.0.0
```

Потом открыть http://127.0.0.1:8000/ в браузере.

## Витрина

Та же страница публикуется на GitHub Pages. Сборка (`server/app/showcase.py`) кладёт рядом с ней `data/rates.json` и `data/settings.json` и включает режим витрины: данные берутся из этих файлов, настройки только для просмотра, статус устройства не показывается.

# web

Страница для пользователя флюгера. Здесь будут текущие курсы, график за неделю и настройки устройства: какие валюты показывать, как часто их менять и при каком скачке мигать светодиодом. Пока это заготовка `index.html`.

## Папки

```
index.html    страница
```

## Как запустить на Windows

Страница будет брать данные с сервера, поэтому сначала запускаем его:

```
cd server
.venv\Scripts\python -m uvicorn app.main:app --reload --host 0.0.0.0
```

Потом открываем `web/index.html` в браузере. Как запустить симуляцию устройства, написано в `firmware/README.md`.

# web

Сайт флюгера: одна страница `index.html` без сборщиков и внешних библиотек. Её отдаёт наш сервер, поэтому отдельно открывать файл не нужно.

## Что на сайте

Тёмный сайт с четырьмя вкладками (адреса `#overview`, `#device`, `#history`, `#settings`):

- Обзор: карточки валют с курсом, изменением за день и маленьким графиком; панель «Устройство сейчас» — большая и маленькая матрица точками, шкала флюгера, светодиод и пищалка для выбранной валюты; график 8 последних курсов с ценами и датами.
- Устройство: то же устройство крупно, выбор валюты, объяснение каждого элемента и таблица — что устройство покажет по каждой валюте.
- История: большой график выбранной валюты с подсказками, таблица курсов по дням (изменение за день и отклонение от среднего) и график сравнения всех валют в процентах.
- Настройки: время показа валюты, порог сильного изменения (сразу видно, у каких валют сработают светодиод и пищалка), какие валюты показывать на устройстве; состояние системы — источник курсов, когда загружены, на связи ли устройство.

Страница подстраивается под телефон и обновляет данные раз в минуту.

## Как открыть

```
cd server
.venv\Scripts\python -m uvicorn app.main:app --reload --host 0.0.0.0
```

Потом открыть http://127.0.0.1:8000/ в браузере.

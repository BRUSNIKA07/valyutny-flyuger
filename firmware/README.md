# firmware — прошивка ESP32 (C++)

Флюгер на сервоприводе, матрица MAX7219, светодиоды тренда, кнопка. Курсы и настройки берутся с сервера по Wi‑Fi (`GET /api/rates` раз в 60 с).

## Запуск в VS Code
1. Расширения: PlatformIO IDE и Wokwi Simulator.
2. Открыть папку `firmware/`, собрать (PlatformIO: Build).
3. Командная палитра → «Wokwi: Start Simulator» (нужна бесплатная лицензия: «Wokwi: Request a Free License»).

## Пины
| Компонент | Пин |
|---|---|
| Сервопривод (флюгер) | GPIO 13 |
| Матрица DIN / CLK / CS | 23 / 18 / 5 |
| LED рост / падение | 26 / 27 |
| Кнопка | 14 |

## Матрица
Каждая валюта — короткие кадры по центру, смена эффектом «вверх»: `USD` → `x100` (только для KZT, MNT) → `82.10` → `▲0.42%` / `▼0.35%`.
Весь цикл кадров занимает `carousel_s`. Если кадр не влезает в 32 точки: сначала убирается `%`, потом включается узкий шрифт цифр.
В `diagram.json` у матрицы `layout: fc16` — должно совпадать с `HARDWARE_TYPE MD_MAX72XX::FC16_HW` в коде, иначе буквы зеркалятся или переворачиваются.

## Wi‑Fi и сервер
- Настройки сети — `src/fluger_config.example.h` (по умолчанию для Wokwi: `Wokwi-GUEST`, `http://host.wokwi.internal:8000/api/rates`).
  Для настоящей платы скопируйте его в `src/fluger_config.h` (в git не попадает) и впишите свои SSID, пароль и адрес сервера.
- В `wokwi.toml` включён `[net] gateway = true`: из симуляции виден компьютер по адресу `host.wokwi.internal`.
- Сервер запускать с `--host 0.0.0.0` (см. `server/README.md`).
- Пока ответа сервера нет или связь пропала, показываются последние полученные данные (до первого ответа — демо) и кадр `no link`.

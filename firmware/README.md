# firmware

Прошивка для ESP32. Плата подключается к Wi‑Fi и раз в минуту забирает курсы с сервера. Большая матрица показывает валюту и курс, маленькая — диаграмму за 8 последних курсов. Флюгер показывает, выше курс среднего или ниже. Зелёный светодиод мигает при сильном росте, пищалка пищит при сильном падении. Кнопкой можно листать валюты.

## Папки

```
src/main.cpp                   код прошивки
src/fluger_config.example.h    Wi‑Fi и адрес сервера (по умолчанию для Wokwi)
platformio.ini                 настройки PlatformIO и библиотеки
diagram.json                   схема для Wokwi
wokwi.toml                     настройки симулятора
```

## Подключение

| Компонент | Пин ESP32 |
|---|---|
| Большая матрица MAX7219 (8 модулей): VCC / GND | 5V / GND |
| Большая матрица: DIN / CLK / CS | 23 / 18 / 5 |
| Маленькая матрица (4 модуля): VCC / GND / DIN / CLK | общие с большой матрицей |
| Маленькая матрица: CS | 4 |
| Сервопривод: сигнал | 13 |
| Сервопривод: питание / GND | 5V / GND |
| Светодиод роста (зелёный, через 220 Ом) | 26 |
| Пищалка (второй вывод на GND) | 25 |
| Кнопка (второй вывод на GND) | 14 |

## Как запустить на Windows

1. Запустить сервер (подробно в `server/README.md`):
   ```
   cd server
   .venv\Scripts\python -m uvicorn app.main:app --reload --host 0.0.0.0
   ```
2. В VS Code открыть папку `firmware` и собрать проект (PlatformIO: Build или `pio run`).
3. F1 → «Wokwi: Start Simulator». Лицензию для Wokwi можно получить бесплатно через F1 → «Wokwi: Request a Free License».

Если всё работает, в Serial появится `[net] Wi-Fi ok`, а потом строка с адресом сервера и `ok`. На матрице будет, например, `USD 82.10 ▼0.35`. Для KZT и MNT курс указан за 100 единиц, поэтому сначала показывается `KZT 16.20/100`, а потом изменение.

На маленькой матрице всё время видна диаграмма текущей валюты. При сильном росте (по умолчанию 1%) мигает зелёный светодиод, при сильном падении пищалка пищит три раза, когда валюта появляется на экране.

Короткое нажатие кнопки переключает валюту, долгое (больше 0,8 с) переключает режим AUTO/MANUAL. Пока сервер не отвечает, на матрице показываются последние данные и `no link`.

Для настоящей платы скопируйте `src/fluger_config.example.h` в `src/fluger_config.h` и впишите туда свою сеть и адрес компьютера с сервером. Этот файл в git не попадает.

# firmware — прошивка ESP32 (C++)

Флюгер на сервоприводе, матрица MAX7219 (8 модулей, 8×64), светодиоды тренда, кнопка. Курсы и настройки берутся с сервера по Wi‑Fi (`GET /api/rates` раз в 60 с).

## Схема подключения
| Компонент | Вывод компонента | Пин ESP32 | Цвет провода |
|---|---|---|---|
| Матрица MAX7219, 8 модулей | VCC | 5V | красный |
| | GND | GND (левый, GND.1) | чёрный |
| | DIN | GPIO 23 | синий |
| | CS | GPIO 5 | зелёный |
| | CLK | GPIO 18 | жёлтый |
| Сервопривод (флюгер) | PWM | GPIO 13 | оранжевый |
| | V+ | 5V | красный |
| | GND | GND (правый, GND.2) | чёрный |
| LED рост (зелёный) | анод через резистор 220 Ом | GPIO 26 | зелёный |
| | катод | GND.2 | чёрный |
| LED падение (красный) | анод через резистор 220 Ом | GPIO 27 | красный |
| | катод | GND.2 | чёрный |
| Кнопка | 1 | GPIO 14 (внутренняя подтяжка) | фиолетовый |
| | 2 | GND.2 | чёрный |

Расположение в `diagram.json`: матрица сверху, ESP32 под ней, справа серво, ниже справа светодиоды с резисторами, слева снизу кнопка.
Провода проложены под прямыми углами и не идут поверх ESP32.

## Матрица
8 модулей 8×8 (64 точки). Строка целиком, по центру, без прокрутки: `USD 82.10 ▼0.35`.
Если строка не влезает (KZT, MNT), два кадра: `KZT 16.20/100`, затем `▼0.10`. Цифры узкие (3 точки), чтобы всё помещалось.
В `diagram.json` у матрицы `layout: fc16` — должно совпадать с `HARDWARE_TYPE MD_MAX72XX::FC16_HW` в коде, иначе буквы зеркалятся или переворачиваются.

## Запуск на Windows: сервер + симуляция
Нужны VS Code с расширениями PlatformIO IDE и Wokwi Simulator (бесплатная лицензия: F1 → «Wokwi: Request a Free License»).

1. Сервер (первый раз — создать окружение и поставить зависимости):
   ```
   cd server
   python -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```
   Запуск (окно терминала не закрывать):
   ```
   cd server
   .venv\Scripts\python -m uvicorn app.main:app --reload --host 0.0.0.0
   ```
   Проверка: http://127.0.0.1:8000/api/rates
2. Прошивка: открыть папку `firmware/`, собрать (PlatformIO: Build или `pio run`).
3. Симуляция: F1 → «Wokwi: Start Simulator». В Serial должно появиться `[net] Wi-Fi ok`, затем `[net] http://host.wokwi.internal:8000/api/rates: ok`.

## Wi‑Fi и сервер
- Настройки сети — `src/fluger_config.example.h` (по умолчанию для Wokwi: `Wokwi-GUEST`, `http://host.wokwi.internal:8000/api/rates`).
  Для настоящей платы скопируйте его в `src/fluger_config.h` (в git не попадает) и впишите свои SSID, пароль и адрес сервера.
- Из симуляции компьютер доступен по адресу `host.wokwi.internal`; в Wokwi для VS Code дополнительных настроек не нужно.
- `--host 0.0.0.0` нужен, чтобы сервер был виден из симуляции и с платы в локальной сети.
- Пока ответа сервера нет или связь пропала, показываются последние полученные данные (до первого ответа — демо) и кадр `no link`.

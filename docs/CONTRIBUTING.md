# Как работаем с git

В репозитории работает один разработчик, поэтому pull request, ревью и защита веток не используются.

- Ветки по областям: `firmware/<что-делаем>`, `server/<...>`, `web/<...>`, `docs/<...>`. Для мелких правок можно работать прямо в `main`.
- Коммиты короткие и понятные: `server: добавлен эндпоинт /api/rates`.
- После каждой завершённой задачи: коммит и `git push origin <ветка>`.
- Крупная задача: своя ветка, затем `git checkout main && git merge <ветка>` и `git push origin main`.
- Перед слиянием проверить, что код запускается (сервер стартует, `pio run` собирается).

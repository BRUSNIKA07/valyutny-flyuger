# Как работаем с git

- `main` защищена: изменения только через pull request, нужен 1 ревью.
- Ветки: `firmware/<что-делаем>`, `server/<...>`, `web/<...>`, `docs/<...>`.
- Коммиты короткие и понятные: `server: добавлен эндпоинт /api/rates`.
- Одна задача = один issue = одна ветка = один pull request.
- Перед PR: `git pull origin main`, проверить, что код запускается.

## Договорённости
- Валюты: CNY, USD, EUR, KZT, MNT (к рублю). Список — настройка.
- Флюгер на сервоприводе показывает изменение за сутки в %: шкала −2%…+2%, угол = 90° + изменение / 2% × 90°.
- Устройство опрашивает `GET /api/rates` раз в 60 с.
- Ответ: `{"date", "rates":[{"code","nominal","rate","change"}], "settings":{"carousel_s","alert_pct"}}`.
- `rate` — цена за `nominal` единиц валюты в рублях (как публикует ЦБ); `change` — изменение за сутки, %.
- `settings.alert_pct` (по умолчанию 1.0) — порог мигания светодиода, `settings.carousel_s` (по умолчанию 10) — смена валюты в авторежиме, секунды; прошивка берёт их из ответа сервера.
- Для KZT и MNT ЦБ даёт курс за 100 единиц (`nominal` = 100). Сервер значения не пересчитывает, а передаёт `nominal` как есть; на матрице пишем `KZT/100 16.20 -0.10%`.
- Дальше (после обязательных этапов): MQTT, курс с Мосбиржи, Telegram-бот, пять флажков на сервоприводах.

# Архитектура

```
[ESP32] <--HTTP--> [Сервер FastAPI] <--HTTP--> [Веб-страница]
                          ^
                          | раз в час
                     [API ЦБ РФ]
```

Устройство раз в 60 секунд спрашивает у сервера `GET /api/rates`. Сервер раз в час берёт курсы у ЦБ РФ (сейчас вместо этого демо-данные). Валюты: CNY, USD, EUR, KZT, MNT к рублю, список можно менять.

## Ответ сервера

```json
{
  "date": "2026-10-05",
  "rates": [
    {"code": "USD", "nominal": 1, "rate": 82.10, "change": -0.35},
    {"code": "KZT", "nominal": 100, "rate": 16.20, "change": -0.10}
  ],
  "settings": {"carousel_s": 10, "alert_pct": 1.0}
}
```

- `rate` — сколько рублей стоят `nominal` единиц валюты, как у ЦБ. У KZT и MNT `nominal` = 100, сервер это не пересчитывает.
- `change` — изменение за сутки в процентах.
- `carousel_s` — через сколько секунд менять валюту на экране, `alert_pct` — при каком изменении мигать светодиодом.

## Что показывает устройство

Стрелка на сервоприводе: 90° — курс не изменился, 0° — упал на 2% и больше, 180° — вырос на 2% и больше. На матрице: `USD 82.10 ▼0.35`, для KZT и MNT — `KZT 16.20/100` и следующим кадром изменение.

Потом, после обязательных работ: MQTT, курс с Мосбиржи, Telegram-бот, пять флажков на сервоприводах.

# Валютный флюгер

Физический индикатор курсов валют: флюгер на сервоприводе поворачивается в сторону роста или падения курса.
Проект по предмету «Проектная деятельность», ДВФУ.

Структура: `firmware/` (ESP32, C++) · `server/` (Python, FastAPI) · `web/` (страница) · `docs/`.
Подробнее — `docs/architecture.md`.

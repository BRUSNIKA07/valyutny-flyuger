# Валютный флюгер

Учебный проект по проектной деятельности, ДВФУ. Устройство на ESP32 раз в минуту берёт курсы валют с нашего сервера и показывает их по-разному: на большой матрице курс и изменение, на маленькой — диаграмма за 8 последних курсов, флюгер на сервоприводе показывает, выше курс среднего или ниже, при сильном росте мигает зелёный светодиод, а при сильном падении пищит пищалка. Сервер берёт официальные курсы у ЦБ РФ.
 
## Папки

```
firmware/   прошивка ESP32 (C++, PlatformIO) и схема для Wokwi
server/     сервер на Python (FastAPI), отдаёт курсы устройству
web/        сайт: курсы, графики и настройки устройства
docs/       описание архитектуры, правила работы с git, презентации
```

## Как запустить на Windows

Нужны Python 3 и VS Code с расширениями PlatformIO IDE и Wokwi Simulator.

Сервер (первый раз):

```
cd server
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Запуск сервера:

```
cd server
.venv\Scripts\python -m uvicorn app.main:app --reload --host 0.0.0.0
```

Сайт с курсами и настройками открывается по адресу http://127.0.0.1:8000/, пока сервер запущен.

Симуляция: в VS Code открыть папку `firmware`, собрать проект (PlatformIO: Build), потом F1 → «Wokwi: Start Simulator». Сервер в это время должен работать.

Подробнее про устройство — `firmware/README.md`, про сервер — `server/README.md`, как всё связано — `docs/architecture.md`.

## Публичная витрина

Сайт также публикуется на GitHub Pages: https://brusnika07.github.io/valyutny-flyuger/ — он открывается у любого человека, даже когда наш сервер и устройство выключены. Раз в час и после каждого пуша в `main` GitHub Actions (`.github/workflows/showcase.yml`) берёт свежие курсы ЦБ (если ЦБ не отвечает — с зеркала cbr-xml-daily.ru), собирает сайт командой `python -m app.showcase` и выкладывает его. На витрине настройки только для просмотра, менять их можно на домашнем сервере.
